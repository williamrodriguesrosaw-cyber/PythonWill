# PythonWill

Projeto de estudo do curso de Python e IA Generativa.

## O que tem aqui
- `exemplo.py`: exemplos simples de Python (variáveis e print)
- `exemplo2.ipynb`: o mesmo tipo de teste, em notebook
- `requirement.txt`: lista das bibliotecas do projeto

## Como rodar
1. Criar o ambiente virtual: `python -m venv .venv`
2. Ativar: `.\.venv\Scripts\activate`
3. Instalar as bibliotecas: `pip install -r requirement.txt`
4. Rodar: `python exemplo.py`
